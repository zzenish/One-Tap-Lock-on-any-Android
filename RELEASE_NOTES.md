# One Tap Lock 1.0.0 — initial preview

- One home-screen tap locks through Android's Accessibility global lock action.
- Native launcher avoids Flutter startup during normal locking.
- Flutter setup explains permission and refreshes safely after Settings.
- No ads, analytics, overlays, polling, wake locks, or release internet permission.
- Requires Android 9 / API 28 or newer.
- Select arm64-v8a, armeabi-v7a, or x86_64 to match your device.
- Formatting, Flutter analysis, widget test, and release build passed.
- Physical-device verification is pending. See README.md for the checklist.
- APKs use a local development signing key; this is a personal-use preview.
